# Dengue Hunter Documentation

This folder contains documentation for the Dengue Hunter AI project.

## Project Overview
Dengue Hunter AI is an AI-powered dengue risk
inspection and management system.

## Main Components
- YOLO-based image inspection
- Dengue risk assessment
- Inspection result analysis
- Intervention tracking
- Closed-loop monitoring

## Documentation
Project architecture, workflow diagrams,
testing reports, and technical documentation
will be maintained in this folder.
